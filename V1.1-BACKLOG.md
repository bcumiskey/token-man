# Token-Man v1.1 backlog

Deferred from the v1.0.4 RC prep (see UAT-REPORT.md for full details). Tracked
here so nothing is forgotten.

## Features and wiring

- **Full OTel receiver implementation.** v1.0 ships with a stubbed protobuf
  decoder that accepts traffic without crashing but extracts no fields. Decode
  spans and counters per OTLP and map to `UsageEvent`s. (UAT §E)
- **`SourceOffline` alert wiring.** The alert kind exists in state.rs and the
  notification body is written, but no code path fires it. Wire it to the
  admin poller and any source that drops to `Offline` status. (UAT §B, §I)
- **Admin API response-shape validation.** Needs a real Admin API session to
  verify field names and edge cases; current parsing is speculative. (UAT §E)
- **Multi-instance guard.** Add `tauri-plugin-single-instance` so launching
  Token-Man twice focuses the existing window instead of running two copies.
  (UAT §I)
- **Keyboard shortcuts.** Ctrl+Q to quit, Shift+× as a secondary quit
  affordance, and a broader accelerator pass. (UAT §I)
- **Minimize to proper 420×28.** Spec calls for a narrower pinned strip; the
  current 540×32 minimum works but isn't the spec'd target. (UAT §C)
- **Window start position.** Spec calls for bottom-right on the primary
  display on first run. The window-state plugin handles subsequent launches;
  initial placement still uses Tauri defaults. (UAT §C)

## Assets

- **Tray icon regeneration.** Generate a face-only mascot at 16/32/48 px for
  the tray, distinct from the full-body splash icon. Requires an asset
  pipeline step from SVG → PNG → ICO. (UAT §H)
- **Real WAV recordings.** `assets/jingle.wav` and `assets/alert.wav` are
  placeholder/zero-byte files. Commission short, distinctive audio cues.
  (UAT §H)
- **Icons via `cargo tauri icon`.** Regenerate the bundled icon set from a
  proper high-res source so the bundle icon, window icon, and taskbar icon
  are consistent and crisp. (UAT §H)

## Engine

- **Tier escalation Warn → Alert re-firing.** When a value crosses from the
  warn tier into the critical tier, the existing alert is updated in place
  instead of firing a new notification. Some users want the second toast.
  (UAT §B)
- **Hysteresis counters in `AppState`.** Currently a `OnceLock<Mutex<…>>` in
  `thresholds.rs`; moving into `AppState` removes the static mutex's
  poisoning risk and clarifies ownership. (UAT §B)
- **`cmd_refresh_registry` persistence.** Refresh writes the registry into
  memory but doesn't persist the new bytes to disk, so a restart reverts to
  the bundled copy. (UAT §D)

## Quality

- **Unit tests.** No test suite ships with v1.0. At minimum: threshold
  engine edge cases, hysteresis counters, cost calculation, context-%
  derivation, rollup aggregation. (UAT §J)

## Deferred from v1.0.6 (audit follow-ups)

- **Headless mode flag.** The v1.0.5 audit Phase 3 was blocked by the
  binary having no `--help`/`--headless` mode; verification had to be
  done by deriving values from DB rows and CTX_DIAG log emissions
  rather than asserting against a binary dump. Needed for automated
  UAT and future audit cycles. Add a `--headless --dump-state` mode
  that writes a JSON snapshot of `build_view()` and exits.
- **Tokenizer 1.22× inflation factor.** Structural — current factor is
  empirically tuned to make CTX% match `/context` on opus-4-7 only,
  with 1.0× on every other model. Needs a real tokenizer and a
  dedicated v1.1 spec for how inflation interacts with rate metrics
  (5h%, week%, tok/min, burn) not just CTX. See audit F7, F9.
- **Display-layer audit.** Deferred to v1.0.7 once headless mode
  exists. The v1.0.6 fixes were computation-side; a display-side audit
  would assert "what's actually on the screen" against the canonical
  computed values.
- **F5 — sub-agent JSONL parent/child de-dup.** Sub-agent files are
  walked as separate sources; if parent JSONL ever embeds the same
  usage events, double-count. Not confirmed reproducible in v1.0.5
  audit; flag for v1.0.7 once headless mode lets us A/B confirm.
- **F6 — ETA currency consistency.** ETA's numerator (tok/min) excludes
  cache_read but includes cache_write; v1.0.6 changed the 5h%
  denominator to include both. ETA still mixes currencies. Decide one
  consistent basis for ETA in v1.0.7.
- **F8 — spectrum "in" definition.** In-memory ticks use
  `input + cache_write`; DB-seed at startup uses
  `input + cache_read + cache_write`. Bars rescale after the first
  hour. Make the DB-seed match.
- **F10 — subscription vs API cost labeling.** Add per-profile flag
  `subscription: bool`; when true, label cost fields as "hypothetical".
- **F11 — cache hit rate global weighting.** Per-source rate uses
  `(input + cache_read + cache_write)`; global weighting uses
  `(input + cache_read)`. Make the weight match the per-source
  denominator.
- **F13 — context window 204,800 → 200,000.** Registry uses 204,800
  (= 200 × 1024); Anthropic's published subscription context window is
  200,000.
- **F14 — promote `cost_today` accumulator from f32 to f64.** Drift
  past ~$16k lifetime. Lower priority since v1.0.6 derives cost_today
  from DB (which is f64 already), but the per-source f32 field is
  still f32.
