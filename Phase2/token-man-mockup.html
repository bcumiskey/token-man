About Token-Man

Token-Man. It really whips the token's ass.

A static HTML preview of the planned always-on-top heads-up display for monitoring token usage across the Claude ecosystem. It unifies visibility across Claude Code sessions, Dispatch runs, claude.ai chat, Cowork, Claude for Chrome, Claude for Excel, and direct API workloads — distinguishing clearly between instrumented sources (showing live context, tokens per minute, cost) and opaque sources (showing only plan-window aggregate from the Admin API).

Placeholder values (—, 0,000, "no active session") indicate where live data will render in the production build. The spectrum bars at the top and the LED strip at the bottom-right are animated here as a design demonstration. Click anywhere on the page to hear the intro jingle.

What the controls do

  • Profile selector — switch between users or view all profiles aggregated. Each profile carries its own accent color, plan type, and API scope.
  • Settings (⚙) — profile management, API keys, red-mode thresholds, notification preferences, source connections.
  • Pin (📌) — toggle always-on-top window behavior.
  • Time window (60S / 1H / 24H) — switch the spectrum to show the last minute, hour, or day.
  • Snap — copy current state to clipboard as a Markdown block, for bug reports or chat pastes.
  • Session rows — click to expand inline with per-session sparkline, cache rate, burn rate, and actions (focus window, /compact, /clear).
  • Registry status — click to check for model registry updates.

Not included in this mockup

  • Real data ingestion — the production build reads ccusage JSONL, OTel exports, and the Admin API.
  • Red-alert mode, which triggers when any live session crosses critical thresholds.
  • Session row expand-in-place with action buttons.
  • Persistent window state, tray integration, Windows notification toasts.

Companion

Pair this HUD with the token-management Claude skill (included in the same distribution) to get both the visual monitoring layer and an in-chat diagnostic skill that Claude invokes when you ask about context, cost, caching, or limits.
